# 🧬 Living NFT - Complete Bio-morphic Digital Ecosystem

A revolutionary NFT system where digital entities evolve, mutate, and interact with real-world environmental data. These are not just static images - they are living, breathing digital organisms that grow, age, and adapt over time.

## 🎯 **Mission**

Create the most advanced bio-morphic NFT ecosystem where digital entities:
- 🧬 **Evolve** through 12-layer DNA systems
- ⚡ **Interact** with real-world environmental data
- 🌍 **Form colonies** and social structures
- 👻 **Experience death and rebirth** through Ghost Protocol
- 📱 **Live in augmented reality** on mobile devices

## 🏗️ **Architecture**

### **Smart Contracts (Ethereum/Sepolia)**
- **LivingNFT.sol** - Core ERC721 contract with evolution mechanics
- **Chainlink VRF** - Random DNA generation and mutations
- **Energy System** - Real-time energy decay and feeding
- **Breeding System** - DNA inheritance and genetic mixing
- **Ghost Protocol** - Death and rebirth mechanics

### **Backend API (Node.js + tRPC)**
- **Real-time WebSocket** - Live updates to all clients
- **Redis Cache** - Environmental data and user stats
- **Cron Jobs** - Automatic lifecycle updates
- **Environmental APIs** - Weather, market, and social data
- **Blockchain Integration** - Direct contract interaction

### **Frontend Dashboard (Next.js + React)**
- **3D Visualization** - Three.js powered NFT rendering
- **Vital Signs Panel** - Real-time health monitoring
- **DNA Laboratory** - Genetic analysis and manipulation
- **Life Timeline** - Complete history and achievements
- **Environmental Dashboard** - Real-world data integration
- **Care Center** - Feeding, breeding, and health management

### **Mobile AR App (React Native + Expo)**
- **AR Camera** - View NFTs in real-world environment
- **Mobile Dashboard** - Full feature set on mobile
- **Haptic Feedback** - Immersive interactions
- **Location Services** - Environmental data collection
- **QR Code Scanning** - Easy wallet connection

## 🚀 **Quick Start**

### **Prerequisites**
- Node.js 20.10.0+
- Git
- MetaMask or compatible wallet
- Expo Go (for mobile)

### **Installation**

1. **Install Visual Studio Tools** (Recommended)
```bash
# Run as Administrator
.\INSTALL_VISUAL_STUDIO_TOOLS.bat
```

2. **Install Project Dependencies**
```bash
# Run as Administrator
.\FIXED_ADMIN_INSTALL.bat
```

3. **Start Complete System**
```bash
# Start all services at once
.\scripts\START_ALL.bat
```

### **Manual Setup**

1. **Smart Contracts**
```bash
cd contracts
npm install
npm run compile
npm run node  # In separate terminal
npm run deploy:local
```

2. **Backend API**
```bash
cd backend
npm install
npm run dev
```

3. **Frontend Dashboard**
```bash
cd frontend
npm install
npm run dev
```

4. **Mobile App**
```bash
cd mobile
npm install
npm start  # Scan QR code with Expo Go
```

## 🌐 **Access Points**

- **Frontend Dashboard**: http://localhost:3000
- **Backend API**: http://localhost:3001
- **Blockchain Node**: http://localhost:8545
- **Mobile AR**: Scan QR code with Expo Go
